# AGENTS.md — Codex & AI Agent Instructions

## Project Context

This repository contains the **nanochat Wiki**, a VitePress documentation site for [nanochat](https://github.com/karpathy/nanochat). It is auto-generated by the Deep-Wiki plugin for GitHub Copilot CLI, then manually curated and hosted on GitHub Pages.

## Repository Layout

- `.vitepress/config.mts` — VitePress config: sidebar navigation, Mermaid theme, head tags
- `.vitepress/theme/` — Custom dark theme with click-to-zoom for images and Mermaid diagrams
- `01-getting-started/` through `07-infrastructure/` — Documentation organized by topic
- `index.md` — VitePress homepage with hero section and feature cards
- `onboarding-guide.md` / `zero-to-hero-guide.md` — Onboarding documentation
- `.github/workflows/deploy.yml` — GitHub Actions workflow for Pages deployment

## Build & Preview

```bash
npm ci                # Install dependencies
npm run build         # Build the VitePress site (output: .vitepress/dist/)
npm run dev           # Start local dev server
npm run preview       # Preview the production build
```

## Key Rules

1. **Do not break the VitePress build.** Always run `npm run build` after changes and verify it succeeds.
2. **Sidebar must stay in sync.** If you add or remove a markdown page, update the `sidebar` array in `.vitepress/config.mts`.
3. **Mermaid diagrams use a dark palette.** Use the color scheme defined in `config.mts` mermaid theme variables. Do not use light-mode colors.
4. **Internal links have no trailing slash** and no `.md` extension (e.g., `/04-training/pretraining`).
5. **Do not modify generated content unnecessarily.** This wiki was generated by Deep-Wiki. Prefer additive changes (new pages, corrections) over large rewrites.
6. **Static assets go in `.vitepress/public/`.** Reference them with absolute paths (e.g., `/logo.svg`).

## Deployment

GitHub Pages deployment is automated via `.github/workflows/deploy.yml`. The workflow:
- Triggers on push to `main` or manual dispatch
- Installs deps, builds VitePress, uploads `.vitepress/dist/` as a Pages artifact
- Deploys using `actions/deploy-pages@v4`

The `base` path in `config.mts` is set to `/nanochat-wiki/` for project-site hosting under `https://<user>.github.io/nanochat-wiki/`.

## Testing Changes

After any content or config change:
```bash
npm run build   # Must exit 0
```
There are no unit tests — the build itself is the validation gate.
